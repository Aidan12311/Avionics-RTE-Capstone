# Avionics RTOS lightweight kernel

A lightweight from-scratch RTOS kernel for an ARM Cortex-M4F that reads a live IMU and streams the board's attitude to a flight simulator, so tilting the board in your hand flies a simulated aircraft. Press the USER button and an on-board PID autopilot levels the aircraft; press again to take control back.

Written bare-metal in C++17 and Thumb-2 assembly on an STM32F429I-DISC1, with no vendor HAL, no CMSIS, no heap and no off-the-shelf RTOS.

```
ICM-42688 --SPI--> sensor --> estimator --> controller --> telemetry --UART--> PC bridge --UDP--> X-Plane
                   (1 ms)     (10 ms)        (50 ms)        (50 ms)            (Python)
```

## Key technologies and why

| Technology | Why |
|---|---|
| Preemptive fixed-priority scheduler (shorter period = higher priority) | The standard, analyzable approach for periodic tasks (Liu & Layland, 1973). |
| SysTick decides, PendSV switches, both at lowest priority | A task switch can never land in the middle of another interrupt. |
| FPU-aware context switcher in Thumb-2 assembly | Ignoring the FPU corrupts registers once tasks mix float and non-float code. |
| Interrupt-driven UART with a lock-free ring buffer | Tasks never wait on a slow serial wire. |
| `Latest<T>` mailbox with an RAII interrupt lock | Multi-float structs aren't copied atomically; this prevents torn reads. |
| Complementary filter (accelerometer + gyro) | Simple, explainable, and good enough for hand-tilting. |
| PID controller with anti-windup, driving a dynamics model | X-Plane's physics is overridden, so the autopilot flies a model of the aircraft; gains come from a design formula, not hand-tuning. |
| Register-level HAL with `constexpr` pins | No magic addresses, and pin setup is checked at compile time. |

## Frontend and bridge (not included)

This repo is the firmware only. There is no frontend or simulator in it:

- **Simulator:** the demo flies [X-Plane 12](https://www.x-plane.com/), installed separately with UDP networking enabled.
- **Bridge:** a small Python script reads the board's telemetry over serial and sends it to X-Plane over UDP. It was **generated by Claude (Anthropic's AI assistant)** and is a demo helper, not part of the firmware. Its full source is below, so save it as `bridge.py`. Run it on the Windows PC running X-Plane with `pip install pyserial` then `python bridge.py --port COM5`.

```python
#!/usr/bin/env python3
"""Bridge: STM32 telemetry (serial) -> X-Plane (UDP). Tilt the board and the aircraft banks and pitches.
Press the board's USER button and its autopilot levels the aircraft; press again to take control back.

    python bridge.py --port COM5

Needs:  pip install pyserial
Run it on the same Windows PC as X-Plane, with a flight loaded and the board NOT attached to WSL.
Ctrl+C stops it and gives X-Plane its physics back.
"""
import argparse, math, socket, struct, sys, time

import serial

G = 9.81
POS = "sim/flightmodel/position/"
PHI, THETA, PSI = POS + "phi", POS + "theta", POS + "psi"
LOCAL_X, LOCAL_Y, LOCAL_Z = POS + "local_x", POS + "local_y", POS + "local_z"
OVERRIDE_PLANEPATH = "sim/operation/override/override_planepath[0]"

UPDATE_HZ = 20.0
STALE_S = 0.5             # no telemetry for this long -> level the aircraft out
LEVEL_RATE_DEG_S = 30.0   # how fast it levels out while telemetry is missing
MAX_BANK_FOR_TURN = 60.0  # the turn-rate formula blows up as the bank approaches 90 degrees
ZERO_WARN_S = 1.0         # roll and pitch at exactly 0.000 this long means the IMU data is dead


class XPlane:
    def __init__(self, host, port):
        self.addr = (host, port)
        self.sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        self.sock.bind(("0.0.0.0", 0))
        self.sock.setblocking(False)
        self.names = []
        self.values = {}

    def write(self, name, value):
        # "DREF\0" + float32 + 500-byte null-padded name
        self.sock.sendto(struct.pack("<4sxf500s", b"DREF", float(value), name.encode()), self.addr)

    def subscribe(self, names, hz):
        self.names = list(names)
        for i, name in enumerate(self.names):
            self.sock.sendto(struct.pack("<4sxii400s", b"RREF", hz, i, name.encode()), self.addr)

    def poll(self):
        while True:
            try:
                data, _ = self.sock.recvfrom(4096)
            except (BlockingIOError, ConnectionError):   # ConnectionError: Windows reports "nothing listening"
                return
            if data[:5] != b"RREF,":
                continue
            for off in range(5, len(data) - 7, 8):
                idx, val = struct.unpack_from("<if", data, off)
                if 0 <= idx < len(self.names):
                    self.values[self.names[idx]] = val


class Telemetry:
    """Reads the board's lines from the serial port:
        'ATT,<ms>,<roll>,<pitch>'                  the attitude to fly
        'CTL,<ms>,<mode>,<aileron>,<elevator>'     mode 0 = free-fly (follows the board), 1 = autopilot
    """

    def __init__(self, port, baud):
        self.ser = serial.Serial(port, baud, timeout=0)    # timeout=0: never block
        self.buf = b""
        self.roll = self.pitch = 0.0
        self.last_rx = None
        self.zero_since = None
        self.autopilot = False                              # True while the board's autopilot is flying

    def poll(self, now):
        self.buf += self.ser.read(4096)
        if len(self.buf) > 4096:                            # no newline for ages: it's noise, drop it
            self.buf = self.buf[-256:]
        while b"\n" in self.buf:
            line, self.buf = self.buf.split(b"\n", 1)
            self._parse(line.decode("ascii", "ignore").strip(), now)

    def _parse(self, line, now):
        f = line.split(",")
        if len(f) == 5 and f[0] == "CTL":
            try:
                self.autopilot = int(f[2]) == 1
            except ValueError:
                return
            if self.autopilot:
                self.zero_since = None                      # a levelled autopilot legitimately sits at 0.000
            return
        if len(f) != 4 or f[0] != "ATT":
            return                                          # STAT lines, boot messages, garbage
        try:
            roll, pitch = float(f[2]), float(f[3])
        except ValueError:
            return
        self.roll, self.pitch, self.last_rx = roll, pitch, now
        if roll == 0.0 and pitch == 0.0 and not self.autopilot:
            self.zero_since = self.zero_since or now
        else:
            self.zero_since = None


def read_start_pose(xp):
    """Where is the aircraft right now? Returns (x, y, z, heading), or None if X-Plane doesn't answer."""
    names = (LOCAL_X, LOCAL_Y, LOCAL_Z, PSI)
    xp.subscribe(names, 10)
    deadline = time.monotonic() + 5.0
    while time.monotonic() < deadline:
        time.sleep(0.05)
        xp.poll()
        if all(n in xp.values for n in names):
            for i, n in enumerate(names):                   # hz = 0 cancels the subscription
                xp.sock.sendto(struct.pack("<4sxii400s", b"RREF", 0, i, n.encode()), xp.addr)
            return tuple(xp.values[n] for n in names)
    return None


def clamp(value, low, high):
    return max(low, min(high, value))


def main():
    ap = argparse.ArgumentParser(description="Fly X-Plane's aircraft by tilting the STM32 board.")
    ap.add_argument("--port", required=True, help="the board's serial port, e.g. COM5")
    ap.add_argument("--baud", type=int, default=115200)
    ap.add_argument("--host", default="127.0.0.1", help="where X-Plane runs")
    ap.add_argument("--xplane-port", type=int, default=49000)
    ap.add_argument("--speed", type=float, default=50.0, help="forward speed in m/s (default 50)")
    ap.add_argument("--lift", type=float, default=300.0, help="metres to raise the aircraft above where it starts")
    ap.add_argument("--alt-band", type=float, default=200.0, help="pitch can climb/descend this many metres from the start altitude")
    ap.add_argument("--hold-altitude", action="store_true", help="pitch tilts the aircraft but never climbs or descends it")
    ap.add_argument("--invert-roll", action="store_true", help="use if tilting right banks the aircraft left")
    ap.add_argument("--invert-pitch", action="store_true", help="use if lifting the nose edge pitches the aircraft down")
    args = ap.parse_args()
    roll_sign = -1.0 if args.invert_roll else 1.0
    pitch_sign = -1.0 if args.invert_pitch else 1.0

    xp = XPlane(args.host, args.xplane_port)
    pose = read_start_pose(xp)
    if pose is None:
        sys.exit(f"No reply from X-Plane at {args.host}:{args.xplane_port}. Is it running with a flight loaded,\n"
                 "and is UDP networking enabled in its settings?")
    x, y, z, psi = pose
    y += args.lift
    y_min, y_max = y - args.alt_band, y + args.alt_band
    y_start = y

    try:
        tele = Telemetry(args.port, args.baud)
    except serial.SerialException as e:
        sys.exit(f"Can't open {args.port}: {e}\nIs the board attached to Windows (usbipd detach) and "
                 "no other terminal (screen/picocom/PuTTY) holding the port?")

    print("Waiting for telemetry from the board ...", flush=True)
    deadline = time.monotonic() + 10.0
    while tele.last_rx is None and time.monotonic() < deadline:
        time.sleep(0.05)
        tele.poll(time.monotonic())
    if tele.last_rx is None:
        sys.exit("No 'ATT,...' lines in 10 s. Wrong COM port, or is the firmware running? (Press the board's RESET.)")

    print("Flying. Tilt the board. Ctrl+C to stop.", flush=True)
    xp.write(OVERRIDE_PLANEPATH, 1)                         # X-Plane stops simulating; we place the aircraft
    shown_roll = shown_pitch = 0.0
    last = time.monotonic()
    next_status = last + 1.0
    warned_stale = warned_zero = False
    last_autopilot = False
    try:
        while True:
            time.sleep(max(0.0, 1.0 / UPDATE_HZ - (time.monotonic() - last)))
            now = time.monotonic()
            dt = min(now - last, 0.25)                      # a stall must not teleport the aircraft
            last = now
            tele.poll(now)

            if tele.autopilot != last_autopilot:
                print("AUTOPILOT ENGAGED: the board is levelling the aircraft itself" if tele.autopilot
                      else "FREE-FLY: the aircraft follows the board again", flush=True)
                last_autopilot = tele.autopilot

            age = now - tele.last_rx
            if age > STALE_S:                               # telemetry lost: level out instead of turning forever
                step = LEVEL_RATE_DEG_S * dt
                shown_roll -= clamp(shown_roll, -step, step)
                shown_pitch -= clamp(shown_pitch, -step, step)
                if not warned_stale:
                    print(f"WARNING: no telemetry for {age:.1f} s, levelling the aircraft", flush=True)
                    warned_stale = True
            else:
                shown_roll, shown_pitch = roll_sign * tele.roll, pitch_sign * tele.pitch
                warned_stale = False

            if tele.zero_since is not None and now - tele.zero_since > ZERO_WARN_S:
                if not warned_zero:
                    print("WARNING: roll and pitch are stuck at exactly 0.000. The IMU data is dead "
                          "(loose wire?)", flush=True)
                    warned_zero = True
            else:
                warned_zero = False

            # Bank turns the aircraft (coordinated turn), pitch climbs or descends it.
            bank = clamp(shown_roll, -MAX_BANK_FOR_TURN, MAX_BANK_FOR_TURN)
            psi = (psi + math.degrees(G * math.tan(math.radians(bank)) / args.speed) * dt) % 360.0
            pitch_rad = math.radians(shown_pitch)
            horizontal = args.speed * math.cos(pitch_rad)
            x += horizontal * math.sin(math.radians(psi)) * dt
            z -= horizontal * math.cos(math.radians(psi)) * dt
            if not args.hold_altitude:
                y = clamp(y + args.speed * math.sin(pitch_rad) * dt, y_min, y_max)

            for name, value in ((LOCAL_X, x), (LOCAL_Z, z), (LOCAL_Y, y),
                                (PHI, shown_roll), (THETA, shown_pitch), (PSI, psi)):
                xp.write(name, value)

            if now >= next_status:
                mode = "AUTOPILOT" if tele.autopilot else "free-fly"
                print(f"{mode:9s}  roll {shown_roll:+6.1f}  pitch {shown_pitch:+6.1f}  heading {psi:5.1f}  "
                      f"alt {y - y_start:+6.1f} m  telemetry age {age:4.2f} s", flush=True)
                next_status = now + 1.0
    except KeyboardInterrupt:
        pass
    finally:
        xp.write(OVERRIDE_PLANEPATH, 0)                     # give X-Plane its physics back
        print("\nStopped. X-Plane's physics is back on, so reset the flight before running again.", flush=True)

if __name__ == "__main__":
    main()
```

## Build and run

```bash
make                                    # builds bin/firmware.elf
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
        -c "program bin/firmware.elf verify reset exit"
```

Telemetry is plain ASCII at 115200 baud: `ATT,<ms>,<roll>,<pitch>`, `CTL,<ms>,<mode>,<aileron>,<elevator>` and `STAT,...`.

## Hardware

STM32F429I-DISC1 and an ICM-42688-P over SPI Mode 3: SCLK PA5, MISO PA6, MOSI PA7, CS PA8, 3V and GND. The USER button is PA0.
